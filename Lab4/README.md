# Lab 4 – Advanced Star Patterns in Python

## 📌 Overview

This lab contains two Python programs based on star pattern printing.
The programs demonstrate the use of nested loops to control rows, columns,
stars, and spaces.

Both programs take input from the user and generate the required pattern
dynamically.

## 📂 Programs Included

1. Hollow Diamond Pattern
File:hollow_diamond.py

- Takes an odd number `n` as input.
- Prints a hollow diamond pattern.
- Uses nested loops to control stars and spaces.
- The upper and lower parts are generated dynamically using loops.
- No separate manually written print statements are used for the two parts.


2. Butterfly Star Pattern

File: butterfly_pattern.py

Takes the number of rows n as input.
Prints a butterfly star pattern.
Uses nested loops to control stars and spaces.
Works for any positive value of n.
The upper and lower portions are generated using loops.


## Concepts Practiced
for loops
Nested loops
range()
User input using input()
Type conversion using int()
Conditional statements
Pattern printing
Controlling spaces and stars
Increasing and decreasing loops
Logical thinking and problem solving


## Objective

The objective of this lab is to understand how nested loops can be used
to create complex patterns using stars and spaces. The programs also
develop logical thinking and understanding of loops, conditions, and
dynamic pattern generation.
