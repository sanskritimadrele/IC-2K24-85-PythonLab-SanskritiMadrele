This lab contains six basic Python programs designed to practice fundamental concepts such as variables,
data types, user input, arithmetic operations, type conversion, strings, and escape sequences.
1. Variable and Identifier Practice

File: variable_practice.py
Declares variables for:
Name
Age
Height
Student status
Prints each variable along with its data type using type().

2. Greeting Program

File: greeting.py
Takes the user's:
Name
Age
City
Displays all information in one sentence using an f-string.

3. Arithmetic Operations

File: arithmetic.py
Takes two numbers as input.
Performs:
Addition
Subtraction
Multiplication
Division
Displays each result with a clear label.

4. Celsius to Fahrenheit

File: celsius_to_fahrenheit.py
Takes temperature in Celsius as input.
Converts the input into a number.
Calculates the Fahrenheit temperature using:
F = (C × 9/5) + 32

5. String Manipulation

File: string_manipulation.py
Takes a full name as input.
Displays:
Uppercase version
Lowercase version
Reversed string
Length of the string

6. Escape Sequence Practice

File: escape_sequence.py
Prints a small receipt/table.
Uses:
\t for tab spacing
\n for new lines
Demonstrates how escape sequences can be used to format output neatly.

#OBJECTIVE
The objective of this lab is to build a strong foundation in Python programming by practicing basic syntax,
input/output, variables, operators, type conversion, string manipulation, and formatted output.
