# Lab 5 – Python Programs

## 📌 Overview

This lab contains two Python programs based on **nested loops, Python lists, and matrix operations**.

The programs are:
1. Star Pattern Program
2. 3 × 3 Matrix Operations

1. Star Pattern

File:star.py
This program takes a positive integer `n` from the user and prints a right-angled star pattern using nested loops.

Concepts Used
User input
for loops
Nested loops
Conditional statements
Pattern printing

2. 3 × 3 Matrix Operations

File: matrix_operations.py

This program takes a 3 × 3 matrix from the user and performs the following operations:
Displays the matrix in proper row-and-column form.
Calculates the sum of all elements.
Calculates the sum of the main diagonal elements.
Finds the largest and smallest element.
Displays the transpose of the matrix.

Concepts Used
Python lists
Nested lists
Nested loops
Matrix traversal
Main diagonal
Transpose
Finding maximum and minimum values
User input

## Learning Objectives

By completing this lab, you will learn:
How to use nested loops.
How to create and manipulate Python lists.
How to work with two-dimensional lists.
How to traverse a matrix using loops.
How to calculate matrix-related values.
How to find the largest and smallest elements.
How to calculate a matrix transpose.
