This repository contains a collection of Python programs developed as part of the Python Programming
Lab. The programs cover basic programming concepts such as conditional statements, loops, nested loops, 
recursion, functions, random numbers, and menu-driven applications.

1. Armstrong Number
Checks whether a given number is an Armstrong number.
Prints all Armstrong numbers within a given range.

2. Prime Number
Checks whether a given number is prime.
Prints all prime numbers up to a given limit

3. Perfect Number
Checks whether a given number is a perfect number.
Prints all perfect numbers up to a given limit.

4. Palindrome
Checks whether a number is a palindrome using arithmetic operations without converting it to a string.
Checks whether a given string is a palindrome.

5. Fibonacci Series
Prints the first n terms of the Fibonacci series using a loop.
Generates Fibonacci terms using recursion.
Counts the number of function calls made by the recursive version.

6. Pattern Printing
Prints the following patterns using nested loops:

Right-angled triangle of stars
Number pattern
Centered pyramid pattern

7. Menu-Driven Application
Combines Programs 1–6 into a single menu-driven application.

Allows the user to select an operation.
Takes the required input.
Executes the selected program.
Handles invalid menu choices.

8. Number Guessing Game
Generates a random number between 1 and 100.
Allows the user to guess the number.
Provides hints such as "Too high" or "Too low".
Limits the user to a maximum of 7 attempts.
Displays the correct number if the user runs out of attempts.

OBJECTIVES
Through these programs, the following Python concepts are practiced:
Basic Python syntax
User input and output
if, elif, and else
for and while loops
Nested loops
Arithmetic operations
Functions
Recursion
String operations
Random number generation
Menu-driven programming
Input validation and error handling
Problem-solving and logical thinking
