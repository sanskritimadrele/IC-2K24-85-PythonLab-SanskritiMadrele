# Lab 3 – Pattern Printing in Python

## 📌 overview

This lab contains three Python programs based on pattern printing.
The programs help in understanding nested loops, loops with decreasing values,
and controlling the number of rows and columns in a pattern.

## 📂 Programs Included

1. Number Pattern
**File:** `number_pattern.py`

- Takes the number of rows/size as input.
- Prints a number pattern with the smallest number at the center.
- Uses nested loops and distance from the center to generate the pattern.

2. Inverted Triangle
File: inverted_triangle.py

Takes the number of rows as input.
Prints an inverted right triangle using stars.
Uses a loop that decreases the number of stars in every row.

3. Square
File : square.py

Takes the number of rows as input.
Prints an square using stars.


🎯 Objective
The objective of this lab is to understand and implement different patterns
using Python loops and nested loops. The lab improves logical thinking and
helps in understanding how loops control rows, columns, and repeated output.
